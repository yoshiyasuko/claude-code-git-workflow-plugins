main ブランチに切り替えて最新化し、リモートで削除済みのローカルブランチをクリーンアップする。「main に戻して」「ブランチを整理して」「ブランチを最新にして」「不要なブランチを削除して」「sync して」などのリクエストで使用する。

## モード制御

$ARGUMENTS

| 引数 | 効果 |
|------|------|
| `interactive` | ブランチ削除前に AskUserQuestion ツールによるユーザー確認を行う |

引数が空の場合は**自律モード**で実行する（デフォルト動作）。自律モードでは削除対象を表示したうえで、確認なしに安全削除（`-d`）を実行する。ただし強制削除（`-D`）は自律モードでも必ずユーザーに確認する。

## 手順

### 1. mainブランチへの切り替えと最新化

```bash
git checkout main && git fetch --all --prune && git pull
```

`git fetch --prune` により、リモートで既に削除されたリモート追跡ブランチがローカルからも除去される。

### 2. 削除対象ブランチの検出

```bash
git branch -vv | grep ': gone]'
```

リモート追跡ブランチが `gone`（リモートで削除済み）になっているローカルブランチを検出する。

該当ブランチがなければ「削除対象のブランチはありません。」と表示してステップ4へスキップする。

### 3. 削除の確認と実行

- **自律モード（デフォルト）**: 削除対象のブランチ名を列挙して表示し、確認なしで削除を実行する。
- **`interactive` 指定時**: AskUserQuestionツールで確認する：
  - 質問文: 「以下のローカルブランチはリモートで削除済みです:\n（該当ブランチ名を列挙）\n削除しますか？」
  - 選択肢: ["全て削除する", "中止"]
  - 「中止」→ ブランチ削除をスキップしてステップ4へ

各ブランチを削除する：
```bash
git branch -d <branch-name>
```

`-d`（安全削除）を使う。マージされていないブランチがあれば警告が出る。`-D`（強制削除）はコミットを失う可能性があるため、どちらのモードでも必ず AskUserQuestion ツールでユーザーに確認してから実行する。

### 4. 結果の表示

実行結果のサマリーを表示する：
- 現在のブランチ: main（最新）
- 削除したブランチ数と名前（あれば）
- マージ未完了で削除できなかったブランチ（あれば）
